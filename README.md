# Nocturne

A relaxing rhythm typing experience with synthesized piano, atmospheric themes, and MIDI import. Type along with the built-in melody, play freely, or listen using supported music embeds.

**[Try the live demo](https://nocturne.jimiljojo.workers.dev/)**

## Run locally

Install Node.js 20 or later, then:

```sh
npm ci --legacy-peer-deps
npm run dev
```

Open the local URL Vite prints. Run `npm run build` to create a static site in `dist/`. No backend, API key, or Lovable subscription is needed.

The app includes built-in piano arrangements and supports your own MIDI files. Listening embeds depend on their third-party providers and availability. Please upload or play only material you have the right to use.
